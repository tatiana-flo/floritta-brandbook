Learning – 20 экранов (19-learning.html, -2, -3): вход «My lessons» (Due · Queue · Done · What changed · KPI месяца), урок с подписью и контрасигнацией, квиз дня, skill check, buddy, план развития; менторские – Drafts, редактор урока, To review, Training register, подписанный документ, Consents, Skills matrix + шторка наблюдения, Assign (шторка), Buddies, Азбука флориста (список, карточка, Additions, Seasons), планы развития команды.
Два меню старой CRM (5 пунктов сайдбара + LearningNav на 9 вкладок) слиты в одну под-навигацию внутри «Learning»; три экрана без входа (Assign, Buddies, Development plans) получили вкладки. Флорист/стажёр видит только свои пять вкладок, менеджер – всё; demo-переключатель «Limited role».
Ошибки сервера, которые старая CRM глотала, теперь показаны блоками: публикация урока, старт skill check без уроков, лимит целей, пустая цель, согласование плана, назначение бадди. Опасные действия без подтверждения (Archive, Pass/Not passed, Ask to sign again, Back to draft, удаление медиа) получили App.confirm.
Цепочка алкогольного допуска показана целиком: подпись пальцем на уроке → «Pass · countersign» в To review → реестр с CSV/печатью → документ с номером лицензии 889934.
Азбука: Save пересинхронизирует форму (нет «вечной грязной» формы), AI-черновик сразу виден, выделение сбрасывается при смене фильтра (скрытые карточки не публикуются), фото для сайта помечено; внешние последствия (сайт flowers-a-z, флаг «токсично для питомцев») подписаны у кнопок.
