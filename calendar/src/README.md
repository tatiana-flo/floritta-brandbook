# Календарь команды в CRM – исходники прототипа

Вкладка «Календарь» в разделе «Задачи»: встречи команды, пики продаж с вехами и запретом отпусков, поставки, самозапись на 1:1, личная iCal-лента, дайджест недели.

`python3 build.py` в этой папке собирает два файла:
- `../index.html` – веб-CRM: `shell.html` (токены и компоненты как в `crm/src/shell.html`) + `data.js` (демо-данные и расчёт дат) + `ui.js` (экраны и панели);
- `../mobile.html` – приложение Floritta Team: `mobile-shell.html` (токены и компоненты как в `staff/src/shell.html`) + тот же `data.js` + `mobile-ui.js`.

Собранные файлы руками не править.

Данные только вымышленные: имена, поставщики, события. Денег на экранах нет. Даты праздников и банковских выходных считаются кодом.
